# Telegram Bot для модерации постов от подписчиков

Бот принимает посты от пользователей, отправляет их администратору на модерацию, и публикует одобренные посты в канал с указанием автора.

## 🚀 Установка и настройка

### 1. Получите токен бота
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте полученный токен

### 2. Узнайте свой Telegram ID
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. Скопируйте свой ID (число)

### 3. Узнайте ID канала
1. Добавьте бота в ваш канал как администратора (с правами на публикацию сообщений)
2. Перешлите любое сообщение из канала боту [@GetMyIDBot](https://t.me/GetMyIDBot)
3. Или используйте формат: `-100XXXXXXXXXX` где X - цифры из ссылки канала

### 4. Настройте бота
Откройте файл `bot.js` и замените следующие значения:

```javascript
const TOKEN = 'YOUR_BOT_TOKEN_HERE';      // Вставьте токен от @BotFather
const CHANNEL_ID = 'YOUR_CHANNEL_ID_HERE'; // Вставьте ID канала (например, '-1001234567890')
const ADMIN_ID = YOUR_ADMIN_ID_HERE;       // Вставьте ваш ID (только число, без кавычек)
```

### 5. Запустите бота
```bash
npm install
npm start
```

## 📋 Функционал

### Для подписчиков:
- Отправка постов на модерацию (текст, фото, видео, аудио, голосовые, документы, GIF, стикеры)
- Уведомление о статусе рассмотрения (одобрено/отклонено)

### Для администратора:
- **Просмотр поступивших постов** с информацией об авторе
- **Одобрение поста** ✅ — публикация в канал с подписью:
  - Имя автора (кликабельное, ведёт на профиль)
  - Хэштег `#от_подписчика`
- **Отклонение поста** ❌ — пост не публикуется, пользователь получает уведомление
- **Блокировка пользователя** 🚫:
  - Команда `/block` (ответом на сообщение)
  - Команда `/unblock <ID>` — разблокировать по ID
  - Команда `/unblockall` — разблокировать всех
- **Статистика** 📊 — команда `/stats`

## 🔧 Команды для администратора

| Команда | Описание |
|---------|----------|
| `/block` (ответ на сообщение) | Заблокировать пользователя |
| `/unblock <ID>` | Разблокировать пользователя по ID |
| `/unblockall` | Разблокировать всех пользователей |
| `/stats` | Показать статистику бота |

## 💾 Хранение данных

Бот использует JSON-файл (`posts.json`) для хранения очереди постов на модерацию. Это означает:

✅ **Посты сохраняются при перезапуске** — если бот перезапустится, все ожидающие посты останутся в очереди  
✅ **Простая структура** — данные хранятся в обычном JSON-файле в папке с ботом  
✅ **Автоматическое управление** — файл создаётся и обновляется автоматически  

> ⚠️ При большом потоке постов (сотни в день) рекомендуется перейти на полноценную БД (MongoDB, PostgreSQL)

### Файлы данных

| Файл | Описание |
|------|----------|
| `posts.json` | Очередь постов на модерацию (создаётся автоматически) |

**Не редактируйте `posts.json` вручную!** Это может привести к потере данных.

## 📝 Примечания

- Убедитесь, что бот добавлен в канал как **администратор** с правом публикации сообщений
- Файл `posts.json` создаётся автоматически при первом использовании — не нужно создавать его вручную
- При перезапуске бота все посты из очереди сохраняются и восстанавливаются
- Для больших проектов с высокой нагрузкой рассмотрите использование полноценной БД (MongoDB, PostgreSQL)
